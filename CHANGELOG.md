# Changelog

## 0.1.0 (2026-07-29)

- Initial release.
- Backend: domain model, REST API, JWT auth, RBAC, training pipeline, inference engine.
- Admin Portal: React dashboard for hierarchy, campaigns, datasets, models.
- Capture App: Android app for WiFi fingerprint collection with offline sync.
- User App: Android app for offline position inference using KNN.
- CI/CD: GitHub Actions workflows for backend, admin-portal, and android.
- Deployment: Dockerfile + docker-compose for backend.
