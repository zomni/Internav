# Project Charter

## Project Name
Indoor Positioning Platform (IPP)

## Purpose
Build a generic indoor positioning platform using WiFi Fingerprinting.

The platform must not assume any specific business domain and should be adaptable to hospitals, offices, universities, shopping malls, warehouses, factories, airports or any indoor environment.

## Core Objectives

- Manage organizations
- Manage sites
- Manage buildings
- Manage floors
- Upload floor plans
- Define positioning grids
- Capture WiFi fingerprints
- Train positioning models
- Publish model versions
- Locate users on a map

## MVP Constraints

- SQLite
- FastAPI
- React
- Kotlin
- scikit-learn
